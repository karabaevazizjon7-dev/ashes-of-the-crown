# Аудит интерфейса Alpha 21

| Раздел | Проверка компоновки | Поведение при длинном содержимом |
|---|---|---|
| История / выборы | Пергаментная колонка + портрет + правая иллюстрация + последствия | Центральная колонка прокручивается; правая колонка прокручивается независимо |
| Карта / атлас | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается |
| Провинции / экономика | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается |
| Армия / бой / северный рубеж / экспедиции | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается |
| Персонаж / люди / дома / спутники / диалоги | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается; горизонтальный список диалогов прокручивается отдельно |
| Совет / городская жизнь / задания | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается |
| Инвентарь / летопись / дополнительные разделы / об игре | Общая книжная рамка и тематическая иллюстрация | Центральная колонка прокручивается |
| Верхняя шапка | Дата, глава, место распределяются по доступной ширине | Однострочный текст сокращается многоточием |
| Нижняя строка | Адаптирована под узкий экран | Длинная подпись версии скрыта в ультракомпактном режиме |

**Результат:** по исходному коду все перечисленные страницы используют общую прокручиваемую область, а правая сторона разворота теперь тоже прокручивается независимо. Визуальная проверка на устройстве и точное сравнение пиксель-в-пиксель не выполнены, поскольку нет Android-сборочной среды и исходного эталонного изображения в доступных файлах.
