# V86 — книжный интерфейс и единая иллюстрация

## Изменения
- Уменьшены верхняя шапка, бренд игры, индикаторы времени/главы/локации и навигационная рейка.
- Убрана дублирующая правая рейка быстрых разделов; дополнительные системы собраны в «Ещё».
- Карта, инвентарь, люди/отношения, спутники и диалоги используют всю ширину книжного поля без правой панели иллюстраций.
- На сюжетной странице справа остаётся только одна иллюстрация; блок последствий удалён из иллюстрационной панели.
- Для всех 21 сюжетных сцен назначены тематические одиночные иллюстрации из набора `scene_art_*`; убраны случайные четырёхкадровые коллажи из сюжетной последовательности. Для «Дороги через Серый Брод» назначена отдельная сцена речной переправы.
- Уменьшен портрет Эдриана; заголовок сцены переведён на системный рукописный шрифт; уменьшены основной текст и варианты выбора.
- Варианты выбора сделаны компактными строками с кликабельной областью вместо высоких Material-кнопок, чтобы сократить вертикальную прокрутку.
- Исправлено устаревшее описание версии схемы сохранений в разделе «Об игре»: 7 → 11.

## Музыка и лицензии
- Существующие локальные темы не удалялись: все семь файлов в `res/raw` остаются в приложении, воспроизведение по контексту/локации сохранено.
- Новые треки из интернета в этот архив не включены: среда выполнения не смогла разрешить внешние домены для скачивания бинарных аудиофайлов. Чтобы не включать музыку с неподтверждённой лицензией, добавлен список подходящих CC0-источников в `docs/MUSIC_SOURCES_FOR_PART_II.md`.

## Совместимость
- Формат сохранений и игровые ключи не менялись.
- Новые сетевые зависимости не добавлялись; игра остаётся офлайн.
