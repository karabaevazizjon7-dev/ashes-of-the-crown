# V89 — сюжетные иллюстрации без коллажей

## Что изменено
- Для всех 21 сюжетной сцены подготовлены отдельные широкоформатные иллюстрации 16:9 (`story_v89_00` … `story_v89_20`).
- Вместо общей подборки с повторяющимися сценами сюжетный экран теперь выбирает иллюстрацию по точному индексу сцены.
- Из многопанельных концепт-листов использованы только отдельные кадры; в результирующие сюжетные изображения не попадают соседние панели.
- Для сюжетных иллюстраций убраны нижние декоративные плашки с подписями там, где они были частью исходного концепта.
- Правая иллюстрационная панель использует `ContentScale.Crop`, чтобы заполнять отведённое окно без пустых полей. Новые сюжетные ресурсы заранее приведены к широкому формату 16:9.
- Добавлен каталог соответствия сцен и изображений `docs/STORY_ARTWORK_V89.md`.
