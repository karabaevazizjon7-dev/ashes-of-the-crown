ASHES OF THE CROWN — VISUAL ASSET CATALOG (ALPHA 4)

The catalog in ASSET_CATALOG.json documents 146 concept-art panels and their source-sheet provenance. The drawable images themselves are already stored once in app/src/main/res/drawable-nodpi/ under stable Android resource names.

The former nested drawable-nodpi/game_art directory contained byte-identical duplicate copies of those 146 images. Android drawable resource directories are intended to be flat; the duplicate staging copies have therefore been removed from the Android resource tree. The catalog and this README are retained here as project documentation.

IMPORTANT
- These are generated concept images, not confirmed canon artwork.
- Some panels contain invented character designs, heraldry, or locations. Do not assign them to new story scenes until checked against the project's story and existing assets.
- Main-cast concept portraits are references, not automatic replacements for established character portraits.
- The catalog is provenance documentation; it does not prove that every image is currently displayed in the game.
- No APK or Gradle build was performed as part of this resource cleanup.
