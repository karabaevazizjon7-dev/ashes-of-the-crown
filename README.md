# Пепел короны / Ashes of the Crown — Android 1.1.0

Тёмная сюжетная RPG для Android в горизонтальной ориентации. Kotlin, Jetpack Compose, локальные сохранения и фоновая музыка.

## Новое в 1.1.0 — личные истории NPC
- Четыре сохраняемые личные линии: Гаррет, Селеста, Мира и Томас.
- Персонажи раскрывают новые сведения постепенно, учитывая доверие, прежние разговоры, выполненные задания и время суток.
- Истории открывают предметы-улики, золото, влияние и поддержку фракций.
- Условия и завершение личных историй сохраняются между запусками.
- Вкладка «Жизнь» получила раздел личных историй и счётчик прогресса.

## Уже присутствует
Сюжетные выборы, репутация и фракции, карта локаций, смена времени суток, распорядок NPC, торговля, задания, инвентарь, пошаговые бои, опыт и навыки, локальная фоновая музыка.

## Сборка
Откройте корневую папку проекта (там, где находятся `settings.gradle.kts` и `app/`) в Android Studio на компьютере. Для сборки APK используйте Build → Build Bundle(s) / APK(s) → Build APK(s). Минимальная версия Android — API 26; compileSdk 35; JDK 17.

## Важно
Архив проверяется на целостность отдельно. Компиляция Android в этой среде не выполнялась; APK не собран и совместимость изменений ещё требует проверки сборкой.

Автор идеи: Aziz Karabaev.

### Как получить APK без компьютера
1. Загрузите содержимое этой папки в новый GitHub-репозиторий (или замените файлы проекта в существующем).
2. Откройте вкладку **Actions** репозитория.
3. Выберите workflow **Android APK** и нажмите **Run workflow** (если сборка не стартовала автоматически после отправки файлов).
4. Дождитесь зелёного статуса. Внизу страницы запуска откройте **Artifacts** и скачайте `ashes-of-the-crown-debug-apk`.
5. Распакуйте архив на телефоне и установите `app-debug.apk`, разрешив установку из выбранного файлового менеджера.

Это debug APK для проверки на устройстве, не подписанный релиз для Google Play. Для публикации понадобится отдельная release-сборка с вашим ключом подписи.

**Статус проверки:** ZIP проверен на целостность. Локальная Android-компиляция здесь не выполнялась, поскольку в среде нет Android SDK и Gradle; успешность сборки подтвердит только запуск GitHub Actions.
