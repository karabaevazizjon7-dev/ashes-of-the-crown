# Alpha 27 — разбиение главного Compose-экрана

## Цель
Уменьшить размер метода `AshesGame`, который в Alpha 26 завершал Kotlin-компиляцию ошибкой `MethodTooLargeException`.

## Изменения
- Блоки страниц `realm_map`, `frontier`, `battle`, `dialogues`, `world`, `council`, `companions`, `houses`, `life`, `quests`, `expeditions`, `more`, `about` и резервная страница вынесены в отдельные локальные `@Composable` функции `RenderPage_*`.
- Маршрутизация `when (selectedPage)` вызывает вынесенные функции вместо хранения всех этих UI-деревьев в одном блоке.
- Игровые обработчики, состояние, сохранения и ключи SharedPreferences не переписывались: компоненты используют существующее состояние через замыкания.
- `versionCode=83`, `versionName=6.0.0-alpha27`.

## Проверки
- Сырые количества `{}`, `()` и `[]` сбалансированы.
- Все 14 вынесенных компонентов присутствуют, маршрутизация вызывает их.
- Архив и три части проверены на целостность и точное объединение.
- **Android/Kotlin-компиляция здесь не запускалась**: Gradle не установлен. Поэтому устранение `MethodTooLargeException` ещё должно быть подтверждено GitHub Actions.
