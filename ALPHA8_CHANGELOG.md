# Ashes of the Crown — Alpha 8

## Soundtrack
- Added six original, procedurally composed 32-second looping OGG tracks: court, city, nature, harbor, mystery, and battle.
- All tracks are bundled in `app/src/main/res/raw/`; playback works offline.
- Existing location/event theme selection now resolves to real tracks instead of falling back to the single ambient file.
- Music can still be toggled from the top bar; the current theme is shown beside the in-game day.
- The compositions were generated for this project and do not use third-party recordings or samples.

## Interface
- Refined the landscape book layout: more space for story text and a larger illustration/choice panel.
- The top status area now identifies the active music theme and keeps autosave status visible.
- Existing navigation, game systems, scene indices, and save keys were retained.

## Build status
- Source package only. No APK build was run in this environment.
