# Version 48 — защита целостности инвентаря

- Исправлен дефект сериализации: добавление имени предмета с разделителем `¦` могло превратить один предмет в несколько записей после перезагрузки.
- `InventoryManager.add` теперь отклоняет разделитель сохранения и управляющие символы.
- Проверки добавлены для прямого добавления и результата крафта; неудачный крафт не расходует ингредиенты.
- Формат списка предметов и схема сохранений не менялись. Старые записи не обрезаются.
